# KRONOS — requirements (software, hardware, AI models and libraries)
# setup.sh installs everything below except the system software; Docker users only need Docker Desktop.
#
# ── SYSTEM SOFTWARE ─────────────────────────────────────────────────────────────────────────────────────────
#   Python 3.11+            tested on 3.12 (Linux, Docker) and 3.14 (macOS)
#   PostgreSQL 16+          with the pgvector extension
#                             macOS (Homebrew):        brew install postgresql@18 pgvector
#                             Ubuntu 24.04 / WSL2:      sudo apt install postgresql postgresql-16-pgvector
#   Node.js 18+ and npm     builds the website (Vite)
#   Ollama (optional)       local AI runtime — https://ollama.com ; without it everything works except the assistant
#   git                     to clone the repository
#   — or, instead of all of the above: Docker Desktop (Windows / macOS / Linux) → docker compose up --build
#
# ── LOCAL AI MODELS (pulled by setup.sh or by the Docker container; ~5 GB, once) ─────────────────────────────
#   llama3.1:8b             answers, summaries, translation (Hindi, Gujarati, Punjabi)
#   nomic-embed-text        768-d embeddings for hybrid (vector + keyword) retrieval
#
# ── HARDWARE ────────────────────────────────────────────────────────────────────────────────────────────────
#   RAM 16 GB recommended (8 GB is enough without the AI) · ~12 GB free disk · GPU optional
#   (NVIDIA via Docker/WSL2 or Apple Silicon make AI answers faster; on CPU they take 1–3 minutes)
#
# ── PYTHON LIBRARIES (backend) ──────────────────────────────────────────────────────────────────────────────
#   pip install -r requirements.txt   (from the repository root; the list lives in backend/requirements.txt)
-r backend/requirements.txt
#     fastapi, uvicorn, pydantic          REST API and web server
#     psycopg2-binary                     PostgreSQL driver
#     pandas, numpy                       data processing
#     scikit-learn                        Isolation Forest (financial anomalies), evaluation metrics
#     torch                               GraphSAGE graph neural network (CPU is enough)
#     networkx                            graph analytics (centrality, communities, paths)
#     rapidfuzz                           fuzzy name matching (identity resolution, prior records)
#     cryptography                        Ed25519 agency signatures on the evidence ledger
#     httpx, python-dotenv                local AI client, configuration
#     pyarrow, pypdf                      real court records (open-data metadata, order text)
#     pytest                              tests
#
# ── WEBSITE LIBRARIES (frontend/package.json; npm install — setup.sh does this) ─────────────────────────────
#     vite 5                              build tool
#     three.js                            3D hero and 3D network graph
#     gsap                                motion
#     react, react-dom, tailwindcss       component library build (the main interface is a single-page app)
#   Loaded at run time from CDNs: Google Fonts (Cormorant Garamond, Inter, JetBrains Mono), GSAP 3.12, three.js r128.
#
